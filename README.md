# Octo VPN Bot

Telegram-бот для продажи VPN-подписок. Подписки выдаются через панель
[Remnawave](https://github.com/remnawave) (VLESS + Reality): пользователь получает одну ссылку
сразу на все локации и переключается между ними в клиенте.

Проект пишется по этапам:

1. **Каркас** — Docker, база и миграции, выбор языка (ru/en), главное меню, профиль, CI.
2. **Подписки** — интеграция с Remnawave, тарифы, пробный период, инструкции по подключению.
3. **Деньги** — оплата Telegram Stars, баланс, рефералка, промокоды, напоминания.
4. **Админка и поддержка** — управление прямо в боте, обращения в поддержку.
5. **Запуск** — скрипты установки панели, нод и бота, резервные копии, быстрая установка для теста. ← сейчас
6. Позже: приём рублей, веб-панель.

## Стек

Python 3.12, aiogram 3, PostgreSQL + SQLAlchemy 2 + Alembic, Redis, Fluent для переводов,
Docker Compose. Зависимости ставятся через [uv](https://docs.astral.sh/uv/).

## Запуск на своём компьютере (Windows)

Без сервера, Docker, Postgres и Redis: база — файл `octo.db`, состояния диалогов в памяти.

1. Скачайте код: [ZIP ветки](https://github.com/lxzrl/octo_vpn/archive/refs/heads/claude/project-thread-dhlako.zip),
   распакуйте.
2. Дважды щёлкните `start-local.bat`. В первый раз он поставит [uv](https://docs.astral.sh/uv/)
   (он сам скачает Python) и спросит токен бота, ваш Telegram ID и VLESS-ссылку.
3. Бот работает, пока открыто окно. Telegram должен открываться на компьютере (например, с
   включённым VPN).

Режим тот же, что у быстрой установки: всем выдаётся ваша VLESS-ссылка, остальное настоящее.

## Быстрая установка для теста

Один сервер, без панели Remnawave: бот, база и Xray-клиент. Нужны токен бота, ваш Telegram ID
и любая рабочая VLESS-ссылка.

```bash
git clone https://github.com/lxzrl/octo_vpn.git /opt/octo
cd /opt/octo && sudo bash install.sh
```

Скрипт спросит:

1. `Токен бота от @BotFather:` → вставьте токен.
2. `Ваш Telegram ID:` → вставьте число (узнать у @userinfobot).
3. `VLESS-ссылка:` → вставьте ссылку `vless://...`.

Через эту ссылку бот ходит в Telegram (`TELEGRAM_PROXY`), поэтому сервер может стоять в России.
Её же бот выдаёт пользователям как ключ (`VPN_PANEL=demo`): всё остальное работает по-настоящему —
пробный период, оплата звёздами, баланс, рефералка, промокоды, напоминания, админка и поддержка.
Повторный запуск `install.sh` обновляет бота и, если нужно, меняет токен, ID и ссылку.

Для боевого запуска с панелью и нодами — [deploy/README.md](deploy/README.md).

## Запуск через Docker

```bash
cp .env.example .env   # заполнить BOT_TOKEN, ADMIN_IDS, POSTGRES_PASSWORD
docker compose up -d --build
docker compose logs -f bot
```

При старте контейнер сам применяет миграции базы.

Запуск на серверах (панель, ноды, бот, резервные копии) пошагово: [deploy/README.md](deploy/README.md).

## Настройка панели Remnawave

Бот работает с панелью Remnawave 3.x через REST API (проверено на 3.4.7).

1. В панели создайте API-токен (Settings → API Tokens) и пропишите его в `REMNAWAVE_TOKEN`.
2. Все ноды используют один инбаунд `VLESS_REALITY` из общего профиля, он включён во
   внутреннем скваде. Новая локация — это новая нода и новый хост на этом инбаунде; сквад
   менять не нужно, пользователи увидят локацию при обновлении подписки в приложении.
   Если сквадов несколько, а выдавать нужно не все, перечислите нужные в `REMNAWAVE_SQUADS`.
3. Лимит устройств (HWID) по плану не нужен: в панели он выключен по умолчанию, не включайте.

Каждый пользователь бота — это пользователь панели с именем `tg_<telegram id>`, без лимита
трафика. Бот меняет в панели только дату окончания; отключает доступ по истечении сама панель.

## Оплата и баланс

- Цены тарифов хранятся в рублях и задаются в админке, тариф без цены не показывается.
  Цена в звёздах = цена в рублях / курс звезды, с округлением вверх.
- При покупке сначала применяется скидка по промокоду, потом списывается баланс,
  остаток оплачивается звёздами. Если баланса хватает, звёзды не нужны.
- Баланс резервируется при выставлении счёта; неоплаченный счёт отменяется через
  `PAYMENT_TTL_MINUTES`, резерв возвращается. Все движения пишутся в `balance_transactions`.
- Рефералу: процент от реально оплаченной суммы первой покупки друга (по умолчанию 20%) и
  от следующих (10%). С покупок балансом бонус не начисляется.
- Если после оплаты панель недоступна, платёж остаётся оплаченным, а подписку
  довыдаёт фоновая задача, как только панель ответит.
- Промокоды трёх видов: скидка в % на следующую покупку, сумма на баланс, дни подписки.
  Создаются в админке: лимит активаций, срок действия, свой или случайный код.
- Напоминания об окончании: за 5, 3, 1 день, за час и в момент окончания. Каждое
  отправляется один раз; уже прошедшие на момент продления не отправляются.

## Админка

Открывается командой `/admin` или кнопкой «🛠 Админка» в главном меню. Доступна только тем,
чей Telegram ID указан в `ADMIN_IDS` (через запятую). Тексты админки только на русском
(`app/locales/ru/admin.ftl`).

- **Статистика**: пользователи, активные подписки, пробные периоды, выручка за сутки,
  неделю, месяц и всё время, сумма на балансах, открытые обращения.
- **Пользователь**: поиск по ID или @username, карточка с подпиской, балансом, оплатами и
  рефералами. Можно продлить подписку на N дней, начислить или списать баланс, забанить.
  Бан закрывает доступ к боту, но не отключает VPN до конца оплаченного срока.
- **Тарифы**: цена в рублях, скрыть или показать тариф.
- **Промокоды**: список, создание пошаговым мастером, включение и выключение.
- **Настройки**: курс звезды, проценты рефералки, пробный период (вкл/выкл, дни, канал).
  Значения из `.env` — начальные; изменённые в боте хранятся в таблице `options`
  и действуют сразу, без перезапуска.
- **Рассылка**: всем, с активной подпиской или без неё. Сообщение (текст, фото, видео)
  копируется как есть; перед отправкой бот показывает превью, после — отчёт о доставке.
  Заблокировавшие бота помечаются и в следующие рассылки не попадают.
- **Обращения**: список открытых (🔴 ждут ответа), история переписки, ответ, закрытие.
- **Оформление**: темы — наборы картинок к экранам бота (главное меню, профиль, подписка,
  подключение, покупка, рефералка, поддержка). Встроены «☀️ Светлая» (по умолчанию) и
  «🌙 Тёмная», сезонные темы добавляются прямо в боте, их можно скрыть или удалить.
  Картинка загружается обычным фото. Если в теме нет картинки экрана, берётся её картинка
  главного меню, а если нет и её — картинка «Светлой». Пользователь выбирает тему сразу
  после языка (если доступно больше одной) и может сменить её в профиле.

Админам приходят уведомления о каждой оплате, о новых обращениях и сообщениях в них,
и о сбоях: недоступная панель, упавшая фоновая задача (не чаще раза в полчаса на тип).

## Поддержка

Пользователь пишет в «💬 Поддержка» текст или скриншот, бот открывает обращение и пересылает
его админам. Ответ админа приходит пользователю в бота с кнопкой «Ответить». У пользователя
одно открытое обращение; закрыть его может он сам или админ.

## Локальная разработка

```bash
uv sync                         # зависимости, включая dev
uv run pytest                   # тесты (по умолчанию на SQLite в памяти)
uv run ruff check . && uv run ruff format --check .
uv run mypy
```

Тесты на PostgreSQL: `TEST_DATABASE_URL=postgresql+asyncpg://user:pass@localhost/db uv run pytest`.

Новая миграция после изменения моделей:

```bash
uv run alembic revision --autogenerate -m "что изменилось"
```

## Структура

```
app/
  bot/
    handlers/     экраны и кнопки
    handlers/admin/ админка
    middlewares/  сессия БД, пользователь и язык, настройки для каждого апдейта
    broadcast.py  рассылки в фоне
    notify.py     сообщения пользователям и уведомления админам
    keyboards.py  клавиатуры
    callbacks.py  данные кнопок
  services/       бизнес-логика: пользователи, подписки и триал, платежи, баланс,
                  рефералка, промокоды, напоминания, настройки, обращения, статистика
  worker.py       фоновые задачи: напоминания, отмена старых счетов, довыдача оплат
  vpn/            клиент панели Remnawave, тестовая «панель», VLESS-ссылка → конфиг Xray
  db/             модели SQLAlchemy и подключение
  locales/        тексты бота: ru/main.ftl, en/main.ftl, админка ru/admin.ftl
migrations/       миграции Alembic
tests/
```

Тексты бота лежат в `app/locales/*/main.ftl`; набор ключей в обоих языках должен совпадать,
это проверяет тест.
