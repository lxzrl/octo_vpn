# Запуск Octo VPN на серверах

Схема: один **управляющий сервер** (панель Remnawave, Caddy, бот, базы) и по одному
**VPN-серверу (ноде)** на локацию: Финляндия, Швеция, Нидерланды. Пользователь получает одну
ссылку подписки, в ней все локации.

```
Telegram ── бот ──► API панели (внутренняя сеть Docker, http://remnawave:3000)
                     │
Пользователь ──► https://panel.домен/api/sub/… (Caddy) ── список серверов
Пользователь ──► нода :443 (VLESS + Reality) ──► интернет
Панель ──► нода :2222 (API ноды, открыт только для IP панели)
```

## Что понадобится

| Что | Параметры | Где |
|---|---|---|
| Управляющий сервер | 2 vCPU, 4 ГБ, Ubuntu 24.04, Нидерланды | Hostkey или Timeweb Cloud, ~€10/мес |
| 3 ноды | 2 vCPU, 2 ГБ, безлимитный трафик, Ubuntu 24.04, FI/SE/NL | THE.Hosting, ~€7/мес каждая |
| Домен | A-запись `panel.<домен>` → IP управляющего сервера | любой регистратор |
| Бот | токен от @BotFather | Telegram |
| Ваш Telegram ID | для `ADMIN_IDS` | @userinfobot |
| Канал | для пробного периода, бот в нём админ | Telegram |

Сначала купите управляющий сервер и **одну** ноду. Проверьте, что VPN работает с мобильного
интернета МТС, Мегафона, Билайна и Т2, и только потом берите остальные ноды.

Для домена лучше зона не `.ru`/`.рф`: такие домены проще заблокировать по требованию.

Все команды ниже выполняются от root по SSH.

## 1. Управляющий сервер: панель

Репозиторий приватный, поэтому клонируйте его с
[персональным токеном GitHub](https://github.com/settings/tokens) (права `Contents: read`):

```bash
apt update && apt install -y git
git clone https://<токен>@github.com/lxzrl/octo_vpn.git /opt/octo
bash /opt/octo/deploy/panel/install.sh panel.ваш-домен.com
```

Скрипт ставит Docker, скачивает официальные файлы Remnawave в `/opt/remnawave`, генерирует
секреты и пароль базы, запускает панель и Caddy (он сам получит HTTPS-сертификат) и
открывает в ufw порты 22, 80, 443. Если SSH на другом порту: `SSH_PORT=2200 bash …`.

Сразу откройте `https://panel.ваш-домен.com` и зарегистрируйтесь: **первый
зарегистрированный становится админом панели**. Пароль длинный, сохраните в менеджер паролей.

## 2. API-токен для бота

В панели: **Settings → API Tokens → Create**, срок побольше (например, 3650 дней). Скопируйте
токен, он понадобится в шаге 5 и для генерации ключей ниже:

```bash
TOKEN='сюда токен'
```

## 3. Профиль Xray с Reality

По умолчанию в панели профиль с Shadowsocks. Замените его на VLESS + Reality:

1. Сгенерируйте ключи Reality и короткий ID:

   ```bash
   curl -s -H "Authorization: Bearer $TOKEN" -H "X-Forwarded-Proto: https" \
        -H "X-Forwarded-For: 127.0.0.1" http://127.0.0.1:3000/api/system/tools/x25519/generate
   openssl rand -hex 8
   ```

   Из первого ответа нужен `privateKey` любой пары (публичный ключ панель вычислит сама).

2. Выберите SNI: популярный зарубежный сайт с TLS 1.3 и HTTP/2, не за Cloudflare, лучше
   у того же хостера, что и нода. От SNI сильно зависит, как VPN работает из России, поэтому
   проверяйте на мобильных операторах.

3. **Config Profiles → Default-Profile**: вставьте [`panel/xray-reality.json`](panel/xray-reality.json)
   и замените `REPLACE_SNI`, `REPLACE_PRIVATE_KEY`, `REPLACE_SHORT_ID`. Сохраните. В профиле уже
   заблокированы торренты (иначе хостеры шлют жалобы) и обращения к локальным адресам.

4. **Internal Squads → Default-Squad**: включите инбаунд `VLESS_REALITY` (после замены профиля
   старый инбаунд из сквада пропадает). Бот добавляет пользователей во все сквады.

Ограничение устройств (HWID) в Remnawave по умолчанию выключено, не включайте его: у нас
нет лимита устройств.

## 4. Ноды

Для каждой локации:

1. В панели **Nodes → Management → +**: название (например, `🇫🇮 Финляндия`), адрес = IP ноды,
   Node Port `2222`. Нажмите **Copy docker-compose.yml**: в нём `NODE_PORT` и `SECRET_KEY`.
2. Скопируйте скрипт на ноду и запустите его:

   ```bash
   # на управляющем сервере
   scp /opt/octo/deploy/node/install.sh root@IP_НОДЫ:/root/
   # на ноде
   bash /root/install.sh IP_УПРАВЛЯЮЩЕГО 2222 'SECRET_KEY_ИЗ_ПАНЕЛИ'
   ```

   Скрипт ставит Docker и ноду, включает BBR и настраивает ufw: открыты SSH и 443, а порт
   2222 доступен только с IP панели.
3. В панели нажмите **Next**, выберите `Default-Profile` и инбаунд `VLESS_REALITY`, **Create**.
   Нода должна стать зелёной.
4. **Hosts → +**: инбаунд `VLESS_REALITY`, адрес = IP ноды, порт 443, название как у ноды
   (`🇫🇮 Финляндия`). Именно хосты попадают в подписку: сколько хостов, столько локаций
   в приложении у пользователя.

## 5. Бот

```bash
cd /opt/octo
bash deploy/bot/install.sh
```

Первый запуск создаёт `/opt/octo/.env` (пароль базы и адрес панели уже вписаны) и
останавливается. Заполните в нём:

- `BOT_TOKEN` — от @BotFather;
- `ADMIN_IDS` — ваш Telegram ID;
- `REMNAWAVE_TOKEN` — токен из шага 2;
- `TRIAL_CHANNEL` — `@канал`, бот должен быть в нём администратором;
- `BACKUP_CHAT_ID` — куда слать резервные копии (ваш ID), можно оставить пустым.

Запустите скрипт ещё раз. Он соберёт и запустит бота и проверит окружение:

```
✅ Telegram: бот @octo_vpn_bot
✅ ADMIN_IDS: 1
✅ База: пользователей 0
✅ Redis
✅ Панель http://remnawave:3000: сквадов 1
✅ Канал @octo_news: бот administrator, нужен administrator
```

Повторить проверку можно в любой момент:
`docker compose -f docker-compose.yml -f deploy/bot/panel-network.yml exec bot python -m app.check`.

Дальше в боте: `/admin` → **Тарифы** → задайте цены, **Настройки** → проверьте курс звезды.

## 6. Проверка перед запуском

1. `/start` в боте, выбрать язык, **Моя подписка → Попробовать бесплатно**.
2. Добавить ссылку в Happ на телефоне, проверить каждую локацию на мобильном интернете
   разных операторов и на домашнем Wi-Fi.
3. Купить самый дешёвый тариф звёздами, убедиться, что срок продлился и пришло уведомление
   в админку.
4. Написать в поддержку и ответить себе из админки.

## 7. Резервные копии

```bash
echo '0 4 * * * root bash /opt/octo/deploy/backup.sh >> /var/log/octo-backup.log 2>&1' \
    > /etc/cron.d/octo-backup
bash /opt/octo/deploy/backup.sh   # проверить вручную
```

Каждую ночь в `/opt/backups` сохраняются базы бота и панели и оба `.env`, копии старше 14
дней удаляются. Если задан `BACKUP_CHAT_ID`, архив приходит в Telegram: это копия вне
сервера на случай, если он пропадёт целиком. В архиве секреты, никому его не пересылайте.

## Обновление

```bash
# бот
cd /opt/octo && git pull && bash deploy/bot/install.sh
# панель (раз в пару недель, сначала прочитайте changelog Remnawave)
cd /opt/remnawave && docker compose pull && docker compose up -d
# нода
cd /opt/remnanode && docker compose pull && docker compose up -d
```

Миграции базы бота применяются сами при старте контейнера.

## Безопасность

- Вход по SSH только по ключу: добавьте ключ в `~/.ssh/authorized_keys` и выставьте
  `PasswordAuthentication no` в `/etc/ssh/sshd_config`.
- Порты панели, баз и Redis наружу не открыты: всё слушает 127.0.0.1 или внутреннюю сеть
  Docker. Снаружи доступны только 80 и 443 (Caddy) и SSH.
- `.env` файлы доступны только root (`chmod 600`).
